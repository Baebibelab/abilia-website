# Site d'Abilia

Le site vitrine d'[Abilia](https://github.com/Baebibelab/abilia), le lecteur de musique pour
Jellyfin sur iPhone, Apple Watch et CarPlay. Site statique [Astro](https://astro.build), en
français et en anglais, animé au scroll, hébergé chez OVH.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # site statique dans dist/
```

Node 22.22 ou plus récent (`.nvmrc`).

Conventions (couleurs, animations, textes, ajout d'une page ou d'une section, mise en ligne) :
[docs/CONVENTIONS.md](docs/CONVENTIONS.md).
